# Provenance

Flowboard began as an adaptation of the Workboard extension from
[openclaw/openclaw](https://github.com/openclaw/openclaw) at commit
`78d6c6c0471723721243d67fb053f3810c622bf8`, imported July 28, 2026.

It has evolved independently since and is **not** kept in sync with upstream.
Upstream changes are neither tracked nor merged, and this repository is the sole
source of truth for Flowboard's behavior.

Attribution for the originally imported MIT-licensed code is in
`THIRD-PARTY-NOTICES`.
