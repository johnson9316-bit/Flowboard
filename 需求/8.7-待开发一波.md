### `flowboard` v5.0.4 —— 工单层，多项目多看板

```bash
openclaw plugins install clawhub:flowboard
```

作者 Simeon（@rasimme），MIT，repo [rasimme/FlowBoard](https://github.com/rasimme/FlowBoard)，要求 Node ≥ 18 + OpenClaw ≥ 2026.6.6。

它正面解决 Workboard 的**多板缺口**，而且做得更多：

- **项目工作区**：goals / decisions / task state 懒加载，专治"agent 跨会话丢上下文"
- **agent-native kanban**：`backlog → open → in-progress → review → done`，多 agent 可见
- **多项目**：`FlowBoard: activate project [Name]` / `FlowBoard: list projects`
- **26 个 widget 的项目总览**、File Explorer、Idea Canvas（节点式头脑风暴 → Specify workflow 生成 spec）
- **Telegram Mini App** 远程访问

⚠️ **两个必须知道的差别**：

1. 它的 dashboard 是**独立进程跑在 `:18790`**，不是嵌进 Control UI 的 tab。所以不是"OpenClaw 看板变多板"，是"多一个专用看板站"。
2. **它和 Workboard 是竞争关系，不是互补**——两套工单模型、两套状态机。要用就选一个当主，**别双开**。
